# Project Memory Auto-Update Rule

## 프로젝트 기억 저장소

이 프로젝트의 루트에 `PROJECT_MEMORY.md` 파일이 있습니다.
이 파일은 프로젝트에 대한 모든 핵심 정보(아키텍처, 캐릭터, 스토리 현황, 파일 구조, 주의사항 등)를 담고 있습니다.

### 필수 행동 규칙

1. **새 대화 시작 시**: 반드시 `F:\Project-F\PROJECT_MEMORY.md`를 먼저 읽어 프로젝트 맥락을 파악하세요.

2. **변경사항 발생 시 자동 업데이트**: 아래 상황이 발생하면 `PROJECT_MEMORY.md`를 업데이트하세요:
   - 새로운 스토리 파일(JSON) 추가/수정
   - C# 스크립트 추가/삭제/구조 변경
   - UI 구조 변경 (버튼 추가/삭제, 레이아웃 변경)
   - 새로운 캐릭터 또는 표정 스프라이트 추가
   - 새로운 배경 이미지 추가
   - 빌드 관련 중요 이슈 해결
   - 다국어 번역 추가/수정
   - 폰트 추가/변경
   - 변경 이력 테이블에 날짜와 함께 기록

3. **절대 잊지 말 것**:
   - 프로젝트 경로는 `F:\Project-F` (C드라이브 아님!)
   - C# 파일은 `encoding='utf-8-sig'`로 처리
   - WebGL에서 시스템 폰트 사용 불가
   - `HalloweenUIBuilder.cs` 수정 시 파일 손상 주의 (Python find() 실패 → 파일 절삭)
